# ked-story-director에서 무대(연출)를 갈라 낸다

> 2026-10-29 소유자: *"이제 무대 프리뷰는 ked-story-compositor 이 레포로 옮겨 주시겠습니까? ked-story-director에서는
> 무대 프리뷰를 사용하지 않을 것입니다."*
>
> 같은 날 정한 것(소유자 선택): **이력째 옮기고 이쪽에서는 무대 쪽만 남긴다** · director에서는 **연출 층 전체**를 걷는다 ·
> 게임이 읽는 **Yarn(대사 + 연출 명령)은 compositor만 낸다** · 대사 **발행**(연출이 붙는 고정본)도 compositor로 옮긴다.

이 저장소는 대사에 연출을 붙이는 툴이다 — 무대 프리뷰 · 터미널 · 연출 추가 · 수치 인스펙터 · Setup 편집 · 에셋 · 발행 ·
게임용 Yarn 출력. 이야기의 뼈대(챕터 · 에피소드 · 선택지)와 대사 글은 `ked-story-director`가 쓴다.

## 1. 출처

| | |
|---|---|

| 이 저장소 `main` · `dev` | 위 커밋 그대로 — 이력 751커밋을 그대로 가져왔다(VnTool → director 때와 같은 방식) |
| director 쪽 짝 | 같은 날 director `dev`에서 연출 층을 걷는다(director `docs/plans/presentation-removal.md`) |

그 위의 이력 — VnTool(`VNStoryEditor_avalonia`)에서 director로 온 경위 — 는 `docs/plans/director-split.md`(이 저장소에도
그대로 있다)가 적는다.

## 2. 결정

| # | 항목 | 결정 |
|---|---|---|
| K1 | 옮기는 방식 | **이력째.** 연출 코드의 blame · log가 살고, 출발점이 빌드되는 상태다 |
| K2 | 무엇을 하나 | director가 연출을 걷듯 **반대로 작가 기능을 걷는다** — 챕터 그래프 · 연출 그래프 · 카드 안 글 칸 · 곁기둥의 대사 편집. 남는 것은 무대 프리뷰와 그 엔진(연출 노드 편집기 · 재생 · 에셋 탐색기 · 발행). (C1에서 연출 그래프도 읽기 전용으로 남기지 않고 통째로 걷었다 — 무대가 제 챕터 · 씬 선택기로 길을 찾는다.) |
| K3 | 데이터 경계 | **director의 프로젝트 파일은 원고다 — 이 툴은 읽기만 한다.** 연출 노드 · 명령 공급 · 연출 배선 · 발행본(대사 · 연출) · 곡선 · 빠른 명령 · 에셋 설정은 이 툴의 **자기 파일**에 산다(두 편집기가 한 파일을 쓰지 않는다) |
| K4 | 출력 | 게임용 **Yarn 묶음 · 곡선 · 문서(CSV)는 이 툴만 낸다.** director는 자기 프로젝트 파일과 챕터 진행 JSON만 낸다 — 한 파일에는 내는 쪽이 하나다 |
| K5 | 발행 | 대사 발행(연출이 붙는 고정본, `vN`)은 이 툴이 한다 — director의 대사를 읽어 이 툴의 파일에 남긴다. director가 대사를 고치면 새 판이 생긴 것으로 보고 다시 발행할 수 있다 |
| K6 | 가지 | 작업 `dev`, 기본 `main`. amend · force-push 금지. 단계마다 CI(Windows) 녹색을 보고 다음으로 |
| K7 | 원고 편집 코드 | **원고를 짓는 명령은 남고, 고치는 조작은 걷는다** (C2b-2b). 챕터 · 에피소드 · 간선 · 조건 · 스탯 · 대사 노드 · 대본 줄을 세우는 `Ensure…` · `Add…`는 이 툴의 테스트가 "director가 써 둔 원고"를 지어 놓고 읽는 쪽(무대 · 챕터 재생 · 발행 · Yarn)을 재는 도구다. 개명 · 삭제 · 이동 · 수정 · 배치 같은 작가 조작은 걷고, 테스트가 그것을 픽스처 준비로만 쓰던 자리는 `ManuscriptFixture`가 모델을 바로 고친다 |

## 4. 열린 것

- 반입 `Ked.Presentation.Core`는 옛 재생 저장소 판(2026-08-20)이다. 정본은 `ked-stage-runtime`이다 — 언제 갈아탈지.
- `<<motion>>`: 런타임에 있고 카탈로그에 없다. 모션 이름은 `ked-motion-tool`이 내는 `motions.json`에서.
- director가 대사를 고친 뒤 이 툴이 그 변화를 언제 · 어떻게 알리는지(다시 열 때 · 파일 감시).
- 문서 프리셋 넷(대본집 · 녹음 대본 · 번역 대본 · 연출표)은 조각 합성(`ResultDocumentComposer`)만 남고 제품에서 닿지 않는다 —
  CSV · 양식 단추를 임시로 접어 둔 것(2026-08-25 소유자)과 함께 다시 볼 일이다. 글로 펴던 미리보기 서식은 C2b-2c에서 걷혔다.
